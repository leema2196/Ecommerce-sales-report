# Ecommerce-sales-data-analysis

# Project Overview

This project analyses E-commerce sales data using  python to identify the sales trends, product performance, city wise revenue and customer payment preferences.

# Tools and Technologies

python

pandas

excel

matplotlib

google colab

# Key analysis

Total revenue and average order value

Product wise sales analysis

City wise revenue analysis

Revenue percentage contribution by city

Payment method analysis

Data visualization using bar charts and pie charts

# Project deliverables

Python Jupyter Notebook

Formatted Excel sales report with four worksheets

# Key Findings

Laptop generated the highest revenue

Mouse had the highest quantity sold

Bangalore generated the highest city wise revenue

# Conclusion

This project demonstrates practical data cleaning, data analysis, data visualization and excel reporting skills using python and pandas
